# 个人配置

把 `assets/profile-template.json` 复制到学习目录 `english-lab/profile.json` 后再修改。共享模板中的 `topics` 故意留空，首次使用从使用者本人取得方向。

主题格式：

```json
{
  "topics": [
    {"name": "psychology", "weight": 3},
    {"name": "history", "weight": 2},
    {"name": "photography", "weight": 1}
  ],
  "excluded_topics": ["celebrity gossip"]
}
```

权重是相对选题偏好，不是必须精确兑现的日历比例。优先选择有可靠英文材料、难度合适且近期未重复的子题。增加主题时询问或从语义判断是追加还是替换；“改成”通常替换，“加入”通常追加。“以后不要某主题”写入排除列表。

| 用户说法 | 应做的修改 |
| --- | --- |
| 改成电影、艺术和城市生活 | 替换主题，等权重；保留其他设置 |
| 历史多一点 | 提高历史相对权重，不重置主题列表 |
| 今天想读篮球 | 本次覆盖，不永久更改 |
| 我只有 30 分钟 | 修改每日时长并减少题量；若说“今天”则只改当次 |
| 我偏基础一点 | 下调句法、词汇和篇幅，不直接推断考试分数 |
| 改成雅思阅读方向 | 调整目标与题型；原创题不能冒充真题 |
| 每天晚上 9 点 | 时间改为 21:00；时区已有就沿用，否则补齐 |
| 我想看中文解析 | 单独生成附页；英文主讲义继续独立可读 |

模板中的六级、54 分钟、周六复盘等均可覆盖。`chinese_notes` 可以为 `on_request`、`always` 或 `never`，默认 `on_request`。`weekly_review_day` 可设 MON–SUN 或 null。总时长变化时重新分配各环节，不能只改封面数字。

`delivery.enabled` 只是配置意图，不能证明任务已经创建。定时任务工具成功后，另存本机 `english-lab/scheduler.json`，至少记录工具返回的任务 ID、实际时间/时区、配置路径与运行环境。勿将该文件随 skill 分享。

修改个人配置时先读取原文件，合并指定字段后保存。不要覆盖同目录其他人的配置；多人共用工作区时为每人建立明确的学习子目录，历史也相互隔离。每次定时运行先读最新配置，主题调整无需新建第二个任务。
