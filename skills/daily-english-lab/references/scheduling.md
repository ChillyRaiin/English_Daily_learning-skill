# 启用和维护每日推送

仅在使用者要求创建/更改推送时使用本文件。制作或分享 skill 不等于授权给所有接收者启动任务；每位接收者自行配置自己的任务。

## 可运行的前提

准备好稳定的学习目录、个人 `profile.json`、主题、当地时间和明确时区。优先用客户提供的时区，不能从用户名、路径或执行主机的时区推断。未提供推送时间时只补问时间；不要用本模板擅自默认每天早上 8 点。

在普通对话里先完整试生成一份，实际验证联网检索、写文件、PDF 字体与页面渲染可用。任务需要在能读取该 skill 和配置、保存文件的运行环境中执行。若宿主不能在计划运行时提供这些能力，先说明限制，不能创建一个仅有定时文字提醒却称为“自动生成 PDF”的任务。

## 创建或更新

1. 发现宿主支持的 automation/scheduled-task 工具并读取当时的定义。在 Codex 桌面，先找 `automation_update`；字段和值以工具当前声明为准，不自行写内部任务文件、不伪造自动化指令。
2. 检查已有任务的 ID 和实际设置。有对应任务就更新它；时间或主题调整不能悄悄创建重复任务。保留未要求修改的通知方式与其他字段。
3. 默认返回同一学习对话；只有使用者明确需要每次独立对话或项目时才选择独立任务。选择 heartbeat、cron 等类型依宿主工具规则，不能以固定类型替代能力检查。
4. 保存提示中注明 skill 位置和该使用者配置的绝对路径，清楚描述本次行动。提示必须要求每次重读配置。主题不再复制成另一份永不更新的清单。
5. 由工具创建/更新；读取返回结果，核对时间、时区、目的地与状态。只有工具确认后才能说“已启用”。保存返回的任务 ID。任务时间采用的时区与个人配置不一致时先解决，不自行猜测夏令时偏移。

可改写为宿主原生提示的正文：

> 使用 daily-english-lab skill，读取此用户学习目录中的最新 profile.json 与 history.jsonl，以配置时区中的今天生成一份英语训练。按最新主题和权重选题；主讲义纯英文，米黄色背景，包含完整原创教学阅读正文、语境词块、推理、核验过的听力、复述、写作、末尾答案与轻量入口。按配置时长缩放任务。生成 PDF 与 Markdown，检查实际嵌入字体、Unicode 映射和逐页渲染后再提供链接。今天已有核验通过的版本时不重复生成或重复通知。新讲义完成或有影响运行的问题时告知使用者；没有变化时保持安静。记录来源与核验状态，不虚构作答或成绩。

这段是人类可读模板，不是可直接提交的工具参数。安装后必须换成实际存在的路径，并按宿主 schema 构造调用。不要预填原作者的账户、对话 ID 或电脑路径。

## 更改与暂停

主题/难度/时长变化：更新 `profile.json`，现有任务会在下一次读到；如果宿主只有内联配置，更新原任务提示中的这一份配置。时间/时区变化：同步更新同一个任务与本地配置。暂停/恢复：使用任务工具并核对返回状态；工具失败不能只改 JSON 后声称成功。

宿主缺少定时工具时，交付已完成的单次训练和可复用任务提示，明确“自动推送尚未启用”。不要另装系统级定时服务作为默认替代。若网络或文件权限阻止运行，说明具体缺少的能力；不无限重试、不隐瞒失败。

## 平台区别

本地计划任务需要电脑开机、应用运行、学习目录可访问；云端任务不能假定能访问使用者电脑上的文件。云端若要使用本 skill，须按宿主支持方式附加 skill、内联非私密配置或使用用户授权的持久存储；普通临时容器路径不能当成永久配置。
