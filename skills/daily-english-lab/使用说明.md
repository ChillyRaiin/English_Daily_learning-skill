# 每日主题英语训练

把自己喜欢的话题变成每天可读、可听、可表达的一份英语讲义。默认六级水平、54 分钟；**主讲义纯英文，米黄色背景，中文解析按需另附**。

## 给朋友的快速用法

把整个 `daily-english-lab` 文件夹交给支持本地 skill 的 Codex/助手安装。Codex 当前个人 skill 目录为 `~/.agents/skills/`，放好后应得到 `~/.agents/skills/daily-english-lab/SKILL.md`。已有其他 skill 目录配置的环境，以该环境实际规则为准。也可以把文件夹放到项目 `.agents/skills/` 中。目录位置依据 [官方 skills 文档](https://learn.chatgpt.com/docs/build-skills)，不是只把单独的 SKILL.md 拷过去。

然后直接说：

> 使用 $daily-english-lab。我想读心理学、历史和摄影，六级水平，每天 30 分钟。请先试生成一份；试运行通过后，设置每天晚上 9 点推送，时区 Asia/Shanghai，返回当前对话。

也可以换成任何自己的方向：

> 我喜欢足球、游戏设计和音乐，英语基础一般。每周一到周五晚上 8 点半，用这些话题帮我练英语，每次 20 分钟。

后续不用改代码：

- “以后改成天文学和电影，电影多一点。”
- “今天只想读篮球，其他设置保留。”
- “把时间改到晚上 10 点。”
- “今天帮我附上中文解析。”
- “暂停每日推送。”

## 每天会收到什么

完整英文教学阅读正文、语境词块及英文释义、阅读推理、可访问的听力材料、复述框架、短写作、末尾答案，以及 15 分钟/5 分钟入口。时长可调整，主题不限于原作者的数学或机器学习兴趣。

助手会在你自己的学习目录保存个人配置和历史；共享 skill 本身不存你的主题、作答、账户或推送 ID。分享给下一个人时只分享原始 skill 文件夹即可。

## 推送与运行条件

安装不等于已经订阅。每个人首次使用时需要给出主题、当地时间和时区，并由自己的应用创建定时任务。必须有可用的定时功能、联网检索和 PDF 文件生成环境；缺少定时工具时仍可手动生成，助手会明确说明自动推送尚未启用。

本地任务需要电脑开机、应用保持运行；云端任务是否可生成文件、保留个人配置，取决于所用平台。不能假定网页版、普通聊天窗口、Codex CLI 与桌面端具有完全相同的定时能力，参见 [官方定时任务说明](https://learn.chatgpt.com/docs/automations?surface=app)。

脚本依赖可由助手检测/安装：`reportlab`、`pypdf`、`pypdfium2`。主讲义字体使用 ReportLab 自带的 Vera 并实际嵌入；中文附页需要本机有合适的 TrueType 中文字体。每次都会生成字体报告和逐页图片，助手应查看后再交付。

这份包没有替你登录任何账号，没有内置 API 密钥，也没有启动你的定时任务。只把 skill 分享给朋友，不会使他们收到你的学习记录或使用你的推送任务。
