# Daily English Lab

把使用者喜欢的话题变成可以持续使用的英语训练。默认六级水平、54 分钟；主讲义纯英文，米黄色纸张背景。中文解析仅在请求时另附，不混进主讲义。

## 首次使用与修改偏好

1. 先从当前对话和已有个人配置中读取明确偏好。缺少兴趣方向时，只问使用者想读哪些主题；准备启用推送时再补齐时间与时区。信息已给出便直接执行。
2. 用 [assets/profile-template.json](assets/profile-template.json) 在使用者指定的可写学习目录创建 `english-lab/profile.json`。未指定目录时使用当前工作区；不要把个人配置写回共享 skill。
3. 主题不设学科白名单。可以是人工智能、文学、体育、游戏、医学科普、音乐等。支持多主题、相对权重、排除方向和临时指定。不要把原作者的数学/机器学习兴趣当成新使用者的偏好。
4. 自然语言“以后改成历史和摄影”“心理学多一点”“今天只想读足球”即可修改。长期偏好写入配置；“今天”只覆盖本次。只改指定字段，保留时间、难度等其他设置。修改含义不明确才追问。
5. 配置字段及例子见 [references/preferences.md](references/preferences.md)。首次展示一行简洁设置摘要；之后不逐次询问常规执行细节。

## 每次生成

读取最新配置、使用者时区中的日期，以及 `english-lab/history.jsonl`（不存在则新建）。同一天已有核验通过的讲义时返回现有文件；明确要求重做时生成带版本号的新文件。主题轮换结合相对权重与近期记录，尽量避免连续复用同一篇文章。

先按主题选择可免费访问的英文材料，实际打开核验。优先官方机构、原始研究、大学、公共媒体与作者原文；一般知识可以选择适合学习的可靠科普。新闻标明发生日期和发布日期；学术年份与网页更新日期分开。无法访问原文时换材料，不把搜索摘要当成读过全文。

默认写一篇 **450–650 词的原创教学正文**，在 PDF 内完整提供，不能只有外链和练习。用事实、例子和论证带动英语训练；不是把中文说明翻译成英文。按能力调整长度和句法，不用生僻词装饰难度。原创综合、改写和原文节选须准确标注，并遵守来源许可及当前工具的引用限制；不能把原文换同义词后当原创，也不能因标“教学”就整篇转载。自行设计的情境要标为 hypothetical。

标准版通常包含：

| 内容 | 默认分钟 | 完成目标 |
| --- | ---: | --- |
| Preview | 2 | 预测主题与核心问题 |
| Reading | 9 | 读正文，辨认主张、证据和限制 |
| Chunks | 8 | 8 个语境词块，英文释义和例句 |
| Reasoning | 7 | 4 个推理题，避免全是细节检索 |
| Listening | 13 | 听前预测、无字幕听、核对与跟读 |
| Retelling | 7 | 准备后连续讲 1–2 分钟，再自查 |
| Writing | 5 | 写 80–100 词，给理由与限制条件 |
| Quick check | 3 | 一个理解小测和自检 |

实际分钟之和必须等于配置的总时长。30 分钟等其他时长应压缩任务量，不照抄 54 分钟内容。另给 15 分钟轻量路径和 5 分钟最低维持路径，均为标准版的子集，不额外叠加到总时长。错过的训练不要求补做。

听力必须有实际核验过的链接、明确播放区间或可识别的片段。区分“核验到页面/字幕”与“实际听过音频”；不能编造时长、字幕或说话者内容。根据可访问的音频或文字稿编题；若只有页面元信息，只安排开放式记录任务，不编精确答案。来源不可用时换资源；确实没有合适资源才说明当次替代练习。

答案与解释统一放在末尾的 **Answer key**，不要紧贴每题提前泄露。复述给结构支架，不用整篇背诵稿取代输出。六级真题仅在找到可核验试卷与答案时使用并注明出处，否则明确标为原创练习。

周复盘按配置启用：只复盘已生成的词块、概念和使用者真实提交的作答。未收到作答时称“易错点自查”，不得虚构个人错误率、成绩或完成记录。

## 文件与字体

按 [references/lesson-format.md](references/lesson-format.md) 写结构化 `lesson.json`。用 `scripts/build_lesson.py` 生成 Markdown、PDF、逐页 PNG 与字体验证报告；优先使用宿主提供的依赖，缺失时按当前环境权限安装 `requirements.txt`。

主 PDF 全英文，包括目录、指令、释义、图注与答案；中文解析另存 `*-zh-notes.pdf`，由使用者请求触发。背景默认 `#F5EBD9`。按内容自然分页，不强塞四页。数学、例句和来源链接必须与正文一致。

所有实际绘字字体都必须嵌入，并有 Unicode 映射；包含所用字形的子集嵌入即可，不要求打包整套字体。不要只注册 `STSong-Light` 这类未嵌入 CID 字体。附带脚本默认使用 ReportLab 自带的可嵌入英文字体；中文附页需要当前机器上有覆盖中文的 TrueType 字体或用户指定的字体。分享包不分发系统字体。

运行脚本后必须查看实际页面图片，检查缺字、乱码、遮挡、越界、空白页与答案顺序。脚本报告不能替代人工视觉检查。可用时再用另一渲染器抽查。失败先修复；本次最多重做两轮仍失败，就交付可读 Markdown 并准确说明 PDF 未通过，不能声称“已验证”。若宿主对制品生成另有标记/交付工具要求，依宿主要求操作。

正式交付到学习目录下 `outputs/YYYY-MM-DD/`，为该日期使用稳定文件名；重新生成时加版本号，保留旧版。日期、主题、来源 URL、文件路径、版本与核验状态写入历史。只保存已获准的学习配置与记录，不把它们装进再次分享的 skill。

## 推送

安装 skill 本身不会启用推送。使用者请求“每天发给我/启用推送/更改时间/暂停”时，读取 [references/scheduling.md](references/scheduling.md)，发现宿主实际可用的定时工具，按其当前定义创建或更新任务。

每次运行都重新读取最新主题配置；不要把初次主题永远固定在定时提示中。没有定时工具或运行环境不支持 PDF 时，明确区分可完成的手动训练和未启用的自动功能，不声称会在后台持续运行。

最终回复简短给出当日主题、预计时长、可用文件与 5 分钟入口。说明已执行的核验和必要限制。应用外邮件、微信群等分发必须由使用者另行指定目的地并授权。
